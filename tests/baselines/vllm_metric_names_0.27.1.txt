# Prometheus *exported sample names* present in vLLM 0.27.1.

# Ground truth, extracted from the SIF image we actually run:
#   apptainer exec --env PYTHONNOUSERSITE=1 $GRIEF_SCRATCH/vllm_0.27.1.sif \
#       python3 -c '<scan vllm/**/*.py for "vllm:*" literals + their
#                    Gauge/Counter/Histogram constructor, expand suffixes>'
#
# Suffix expansion follows prometheus_client: a Counter named X exports
# X_total and X_created; a Histogram named X exports X_sum/X_count/X_bucket

# paired statically (dynamic prefixes, e.g. the kv_offload family) get every
# suffix, so this list is a deliberate *superset* -- it is used as an
# allow-list by tests/test_monitor.py::TestScrapedMetricNamesExist, whose job
# is to catch names that exist in NO version (vllm:gpu_cache_usage_perc,
# vllm:num_requests_finished, vllm:num_requests_swapped, ...).
